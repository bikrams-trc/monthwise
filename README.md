# MonthWise

A Punjabi-themed monthly glance calendar for Sikh and Punjabi observances.

## Features

- Clean month overview (not a day-by-day planner)
- Predefined observances (gurpurabs, festivals, memorials)
- **Pooranmashi** and **Sangrand** added by default for every month
- Add, edit, and delete events (pick from the list or enter a custom name)
- Persist on-device via `localStorage`
- One-page year PDF export (max 5 selectable events per month)
- Free month/year navigation · works on mobile and desktop

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
